# Tabletop prototype audio

The `tabletop_*.wav` files are original procedural audition sounds generated by
[generate_tabletop.py](generate_tabletop.py), using only oscillators and seeded noise.
No third-party recordings were downloaded or incorporated. These are prototype candidates,
not the final recorded dice/pawn pack proposed in plan 010.

The dice impacts are placed at 50, 140, 240, 340, 460, and 540 ms to accompany the
600 ms roll. Movement contacts play at the end of each visible step. Sources are
retained so the pack can be regenerated or retuned. All assets are bundled offline.

Format: mono, 22,050 Hz, 16-bit PCM WAV, with endpoint fades and peak headroom.
Audition on device before selecting the final sonic direction.
